# Telegram-бот "Words_Gym_Bot"

Бот для изучения английских слов с помощью карточек. Пользователи могут тренироваться на базовом наборе слов и формировать свой личный словарь.

## Функционал
- **Тренажёр**: Выбор правильного перевода из предложенных вариантов.
- **Управление**: Добавление/удаление собственных слов в базу данных .
- **Многопользовательская поддержка**: Бот запоминает состояние каждого пользователя отдельно.

## Что необходимо для работы бота
- **Python 3.x**
- **pyTelegramBotAPI**: библиотека для работы с Telegram API.
- **PostgreSQL**: реляционная база данных для хранения слов и связей.
- **psycopg2**: драйвер для подключения к БД.

## База данных
Спроектирована база данных, состоящая из 3-х таблиц:
1. `words` — общий словарь слов.
2. `users` — информация о пользователях бота (их Telegram ID).
3. `user_words` — связующая таблица (многие-ко-многим), которая определяет, какие именно слова добавил конкретный пользователь.
4. Схема БД представлена в файле `db_schema.png`.

## Как запустить проект

### 1. Подготовка базы данных
Создайте базу данных `english_cards_db` в PostgreSQL.

### 2. Настройка окружения
Склонируйте репозиторий и установите необходимые библиотеки:
```bash
pip install -r requirements.txt
```

### 3. Настройка параметров
В файлах `TelegaBot.py` и `database.py` укажите свои данные:
- `token_bot` — ваш токен от BotFather.
- `password` — ваш пароль от PostgreSQL.

### 4. Запуск
Сначала инициализируйте базу данных (создание таблиц и начальное заполнение):
```bash
python database.py
```
Затем запустите самого бота:
```bash
python TelegaBot.py
```
